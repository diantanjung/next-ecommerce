
# Next Ecommerce

[![Vercel Deployment Status](https://vercel.com/button)](https://mern-real-estate-woad.vercel.app)

## About Project
This project is a full stack e-commerce store built with Next.js , Shadcn-ui, Stripe, MongoDB, Prisma, NextAuth, and Vercel.
Read article for detail : https://medium.com/@diantanjung/build-a-production-ready-full-stack-e-commerce-store-with-next-js-a-comprehensive-guide-4d07fb648838

## ✨ What We want to Build

-   **Home Page:** carousel hero section, list products/newest arrivals
-   **Detail Product Page** 
-   **Add to Cart Page** 
-   **Checkout and Payment Page** 
-   **Login Page:** with email and password or google or github

## 💻 Technologies Used

This project is crafted using a robust and highly sought-after modern web development stack:

-   **NextJS:** One of the most popular React frameworks with a large user community.
-   **Shadcn-UI:** A UI component library based on Tailwind CSS.
-   **Stripe:** A module for processing payments via credit cards, PayPal, and others.
-   **MongoDB:** A document-based database known for its fast query performance.
-   **Prisma ORM:** A database ORM (Object-Relational Mapping).
-   **NextAuth:** A library for managing user authentication.
